# Legacy evaluation artifacts

This directory contains superseded evaluation runs retained for audit and
reproducibility. Historical artifacts keep their original versioned names and
sealed contents.

The active configuration-4 M4 evaluation uses the plain `data/eval/m4/lineage/`
path. The completed configuration-3 predecessor is archived as `m4-config3/`;
earlier required generations have explicit historical names.

Paths recorded inside sealed legacy JSON are historical provenance and are not
rewritten when an artifact is archived.
