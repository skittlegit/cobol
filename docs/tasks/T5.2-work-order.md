## Amendment 2026-07-28 — gate 4 renumbered to the actual T5.1 outcome

Gate 4 as originally ratified assumed all 51 real-curated candidates would
survive annotation cleanly (51 rows, 20 intact T6 pairs). T5.1's
protocol-correct adjudication — following ANNOTATION.md's own fail-closed
rules, not a shortfall in execution — resolved only **43/51** candidates to
a final label; the other 8 were explicitly excluded (7 for the documented
P1 calendar/working-day ambiguity with no decisive primary authority found,
1 for an unresolved clause-scope question). Of the resulting 43 rows, only
**9** form intact byte-identical-locus verdict-flipping pairs (T6BO02 and
T6BO04 land on the same class on both clause versions by construction —
both omit one leg of a disjunctive capital-or-profits check — so they do
not verdict-flip even though both sides survived).

Forcing the original 51/20 would require either fabricating a label for a
candidate the protocol correctly flagged as unresolvable, or silently
loosening the fail-closed exclusion rule that gives T5.1's annotation
integrity claim its meaning. Neither is acceptable. Gate 4 below is
amended to the achieved counts (43/9) as the new frozen floor;
`src/cobol_archaeologist/benchmark/freeze.py`'s `FreezeManifest` bounds and
internal validation are updated to match and to explicitly support (not
silently paper over) an excluded-candidate path: every candidate absent
from the resolved real rows must carry an immutable `exclude` adjudication
record, checked by `tests/test_benchmark_freeze.py`'s new regression
coverage. See `FLAGS.md` (Track B inbox, resolved) and `STATUS.md`'s T5.1
entry for the full accounting.

## Objective

Promote the purpose-valid `v1-pre` split into the immutable benchmark v1 only
after all 51 real-curated candidates have a human primary annotation, a
separate Claude verification pass, measured pre-final-review agreement, and a
complete human final-review record. Publish a datasheet that makes composition,
provenance, leakage controls, limitations, and intended use reviewer-auditable.

## Frozen inputs and exclusions

- Synthetic rows remain the accepted T2.3/T2.4 catalogue rows already selected
  by T2.7. T5.2 does not regenerate or re-judge them.
- Every surviving real-curated test row is replaced by the resolved T5.1 record
  with the same instance ID; candidates explicitly excluded by human final
  review are absent from v1 and listed in the manifest.
- Train/dev/test base-group isolation, test-local real reservation, and T6
  byte-identical-locus pairing remain hard gates.
- No row moves between splits after the freeze command writes the manifest.
- Gold-only fields remain absent from every system input.
- M4 artifacts remain historical evidence. If adjudication changes any
  detector-visible clause or source identity, T5.4 must rerun affected systems;
  a gold-only label correction may be rescored without provider execution.

## Freeze gates

1. The two locked annotation passes cover exactly the 51 blinded candidate IDs
   under different annotator identities.
2. The agreement report is generated before adjudication and includes raw
   agreement, bootstrap intervals, Cohen's kappa, Krippendorff's alpha, and
   structured disagreement counts.
3. Every differing candidate has one immutable adjudication record; no
   `needs_adjudication` decision remains.
4. All 605 rows (307 train, 102 dev, 196 test) round-trip `DriftInstance`;
   test contains **43** real-curated rows and at least **9** intact
   verdict-flipping T6 pairs — amended 2026-07-28, see amendment note above.
5. Base-program groups do not cross splits, all T2.7 purpose gates remain
   green, and the artifact-only surface AUC interval still includes 0.5.
6. `data/benchmark/v1/manifest.json` records schema version, source hashes,
   split hashes, counts, annotation evidence hashes, compiler policy, clause
   archive pins, and whether detector-visible fields changed.
7. `DATASHEET.md` reports motivation, composition, collection/generation,
   annotation and agreement, preprocessing, leakage controls, recommended
   metrics, limitations, licensing, maintenance, and the M4 NO_GO without
   implying benchmark difficulty proves method quality.

## Completion rule

T5.2 becomes `done` only in the same commit that writes the immutable v1
artifacts, final datasheet, manifest hashes, and completion evidence here.
Preparing tooling or templates is not a freeze.
