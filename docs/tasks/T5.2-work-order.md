# T5.2 work order — benchmark freeze and datasheet

**Owner:** Track B  
**State:** ratified 2026-07-27; blocked on T5.1 independent annotation  
**Depends on:** T5.1 done; T2.7 frozen inputs  
**Canonical artifacts:** `data/benchmark/v1/`, `DATASHEET.md`

## Objective

Promote the purpose-valid `v1-pre` split into the immutable benchmark v1 only
after the 51 real-curated rows have two independent annotations, measured
pre-adjudication agreement, and a complete adjudication record. Publish a
datasheet that makes composition, provenance, leakage controls, limitations,
and intended use reviewer-auditable.

## Frozen inputs and exclusions

- Synthetic rows remain the accepted T2.3/T2.4 catalogue rows already selected
  by T2.7. T5.2 does not regenerate or re-judge them.
- All 51 real-curated test rows are replaced by the adjudicated T5.1 records
  with the same instance IDs.
- Train/dev/test base-group isolation, test-local real reservation, and T6
  byte-identical-locus pairing remain hard gates.
- No row moves between splits after the freeze command writes the manifest.
- Gold-only fields remain absent from every system input.
- M4 artifacts remain historical evidence. If adjudication changes any
  detector-visible clause or source identity, T5.4 must rerun affected systems;
  a gold-only label correction may be rescored without provider execution.

## Freeze gates

1. The two locked annotation passes cover exactly the 51 blinded candidate IDs
   under different annotator identities.
2. The agreement report is generated before adjudication and includes raw
   agreement, bootstrap intervals, Cohen's kappa, Krippendorff's alpha, and
   structured disagreement counts.
3. Every differing candidate has one immutable adjudication record; no
   `needs_adjudication` decision remains.
4. All 613 rows (307 train, 102 dev, 204 test) round-trip `DriftInstance`; test
   contains 51 real-curated rows and at least 20 intact verdict-flipping T6
   pairs.
5. Base-program groups do not cross splits, all T2.7 purpose gates remain
   green, and the artifact-only surface AUC interval still includes 0.5.
6. `data/benchmark/v1/manifest.json` records schema version, source hashes,
   split hashes, counts, annotation evidence hashes, compiler policy, clause
   archive pins, and whether detector-visible fields changed.
7. `DATASHEET.md` reports motivation, composition, collection/generation,
   annotation and agreement, preprocessing, leakage controls, recommended
   metrics, limitations, licensing, maintenance, and the M4 NO_GO without
   implying benchmark difficulty proves method quality.

## Completion rule

T5.2 becomes `done` only in the same commit that writes the immutable v1
artifacts, final datasheet, manifest hashes, and completion evidence here.
Preparing tooling or templates is not a freeze.
