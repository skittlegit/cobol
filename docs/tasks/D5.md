## Approach

1. **Smoke:** 7 dev rows (one per class) to confirm that the WSL runtime, the
   bridge, and `check_finding` work end to end.
2. **Tuning rounds:** a fixed 30-row dev subset, stratified by class and
   interprocedurality, at `high` effort to save usage. Read the errors, adjust
   the D4 items, and repeat (3–5 rounds).
3. **Full dev run** at `max` effort with the final detector version.

## Done when

detector method (`codex.method_hash()`, recorded in every run key) is frozen
for E1.
