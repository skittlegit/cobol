# D2 — `check_finding` self-check inside the task

**State:** done offline; live behaviour is measured in D5.

## Problem

In 36 of the 57 abstentions in the last run, the model's own hypothesis was
correct, but a host check rejected the final answer (rationale wording, static
hook tokens, line labels, citation entailment, ledger). The model never saw
the rejection reason.

## Change

`python -m cobol_archaeologist.eval.bridge ALIAS check_finding --arguments
DRAFT` runs the exact host finalization (`detector.finalize_case`: ledger,
class guard, verifier) on a draft and returns the precise rejection. It allows
at most 6 checks per case. The host still re-runs every check on the submitted
answer from trusted logs, so no rule is relaxed and no label is exposed.

The WSL support runtime now installs CPU `torch` and `transformers`, so the
in-task verifier uses the same DeBERTa entailment model as the host.

budget.
