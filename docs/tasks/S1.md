# S1 — Project site

**State:** done

## Goal

A static public site for the project: what the system does, how the detector
investigates and verifies, the benchmark, and the official result. It is
generated from the repository's canonical files, so it never holds a second
copy of any number.

## Approach

1. `scripts/build_site.py` exports every number the site shows to
   `web/src/site.json`, computed from `data/eval/test/report.json` and the
   benchmark files. The web app in `web/` (React, Tailwind, shadcn/ui) lays
   that file out and builds into `site/`. Neither file is committed.
2. Pages: overview; how it works (tools → finding → verifier → class guard);
   benchmark (classes D1–D7, split counts, temporal pairs); results (gate
   table, decision, per-class F1, detector vs `rag_reranker`); one worked
   example finding with its source lines and clause.
3. Publish with GitHub Pages from `site/` on `master` (workflow in
   `.github/workflows/`).

## Done when

`python scripts/build_site.py` regenerates the site from the current report
with no hand-edited numbers, a test checks that every gate value on the
results page equals `report.json`, and the Pages workflow deploys it.
