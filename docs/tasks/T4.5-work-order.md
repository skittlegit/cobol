## Objective

same frozen rows, then issue the Week-10 M4 go/no-go result without changing
the bars after seeing the data.

## Baselines

1. Dense-RAG single-shot: clause retrieval plus bounded code context, no loop.
2. Oracle-slice single-shot: gold slice variables select Track A's real slicer;
   the model receives that slice but no labels/rationale.
3. Agent: T4.1 bounded policy loop.

All systems use the same model family, decoding settings, instance order, and
paired bootstrap samples. Provider failures remain paired unavailable rows.

## Frozen decisions

- T1 F1 must be at least 0.70 overall.
- Agent minus dense-RAG on the interprocedural stratum must be at least +0.10,
  with bootstrap 95% CI excluding zero and paired-test p < 0.05.
- Oracle-slice deconfounder is mandatory: if the agent does not beat it on the
  interprocedural stratum, reframe the contribution as the slicer before scale.
- T6 reporting bar is paired accuracy at least 0.70 on at least 20 pairs, with
  exact binomial interval. Insufficient pair count is `NOT EVALUABLE`, not pass.

## Gates

The report refuses a go/no-go verdict when artifacts, paired rows, provenance,
human verifier labels, or required baselines are missing. A valid no-go is a
completed checkpoint; an unevaluable run is not.

## Completion

confidence intervals, paired significance, tier faithfulness, coverage, T6,
and the oracle-slice decision.

## Integrated M4 decision and consequences

This section incorporates the former M4 decision sidecar. The configuration-1
NO_GO at commit `357f483` remains the result of record and is not replaced by
later diagnosis or corrective work.

### What the run established

- Agent T1 F1 was 0.3665, below the frozen 0.70 bar.
- On the 36 interprocedural rows, the agent trailed dense-RAG by 0.3030 F1
  (95% CI [-0.4929, -0.1252], paired p=0.00635). The interval excludes zero.
- Agent T6 paired accuracy was 2/20 (0.1000), exact 95% CI
  [0.0123, 0.3170]. Its upper bound is below the 0.5 version-blind floor, so
  the system-level versioned-judgment claim is withdrawn.

### What the run did not establish

The oracle-slice delta was -0.1964 with 95% CI [-0.4330, +0.0348]. That
comparison is underpowered and statistically inconclusive. It does not support
the earlier inference that slicing, rather than the agent loop, is the
demonstrated enabling capability. T0.6's pre-authorised slicer-first fallback
sentence is therefore retired.

### Scale-or-fix decision

The decision is **FIX, not scale**. Configuration 1 answered too few rows to
justify benchmark scale-up. Track B's T5.1/T5.2 hold remains in force; the
benchmark inputs and Track A tools are not implicated by this decision.

## Integrated F1/F2 triage and corrected diagnosis

This section incorporates the former F1/F2 triage sidecar and its same-day
correction.

### F1 — 49 `resolve_copybook` abstentions

Track A is cleared. Across the 49 affected rows, `resolve_copybook` was invoked
zero times, while the tool layer completed 4,570 successful observations over
the full run.

The initial diagnosis—that D1 required copybook evidence unconditionally—was
wrong. `D1Hunt.validate_response` was already conditional on a predicted
locus having `file` set. The implementation replay established:

- 47/49 proposed predictions set `SourceLocus.file` to the program filename,
  such as `CLOSPEN1.cbl`, falsely asserting a copybook locus;
- the other two rows, `drift_323235` and `drift_479980`, genuinely cite
  `WSCUTOFF.cpy` and correctly remain subject to copybook evidence;
- D4 had a separate latent unconditional `resolve_copybook` requirement.

The final root cause is Track C prediction-schema ergonomics, not a Track A
tool gap.

### F2 — 36-row interprocedural stratum

| System | Coverage | Answered accuracy | Correct / 36 |
|---|---:|---:|---:|
| Agent | 9/36 (25%) | 0.556 | 5 |
| dense-RAG | 19/36 (53%) | 0.474 | 9 |
| Oracle-slice | 15/36 (42%) | 0.067 | 1 |

Coverage explains the interprocedural gap: dense-RAG wins by answering twice
as often despite lower per-answer accuracy. Only 2 of the agent's 27

The remaining generic defects were a fixed three-observation guard,
composite-clause leaf confusion, and weak Tier-3 findings. The proposed
entailment-threshold relaxation was withdrawn after the independently labelled
verifier set scored 49/50 with zero false negatives while Tier-3 findings had
only 0.31 drift-type accuracy and 0.0625 faithfulness.
