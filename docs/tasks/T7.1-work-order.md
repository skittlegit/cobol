# T7.1 work order — MCP server over the frozen tool layer

**Owner:** Track A

**State:** ratified 2026-07-27

**Depends on:** T1.6 done; M4 is not a dependency

**Scope:** stdio MCP exposure only. HTTP/authentication and the air-gapped
deployment bundle belong to T7.2.

## Objective

Ship a locally runnable Model Context Protocol server that exposes every method
of the frozen `tool_types.ToolLayer` through Track A's existing
`tools.RealToolLayer`. The MCP boundary is an adapter, not a second
implementation: return models, truncation, source coordinates, lookup errors,
compiler behavior, and regulation-search semantics must remain those of T1.6.

## Locked implementation

1. Use the official Python MCP SDK v1 with the dependency range
   `mcp>=1.27,<2`. Version 2 is not adopted implicitly on its release boundary.
2. Add the console entry point `cobol-archaeologist-mcp`.
3. Default to the stdio transport. T7.1 must not open a network listener.
4. Require an explicit corpus root, supplied by `--corpus-root` or
   `COBOL_CORPUS_ROOT`. Accept repeatable `--copybook-path` values, falling back
   to the platform path-separated `COBOL_COPYBOOK_PATHS` value.
5. Register exactly these eleven tools with the contract names:
   `read_paragraph`, `read_program`, `find_callers`, `find_callees`,
   `trace_variable`, `slice_on`, `resolve_copybook`, `get_data_layout`, `grep`,
   `run_cobol`, and `search_regulations`.
6. Return the existing Pydantic contract models directly so MCP structured
   output is generated from the same types. `run_cobol` accepts `stdin` and a
   file mapping at the wire boundary and constructs the frozen `RunInputs`
   model before delegation.
7. Do not catch `ToolLookupError` or convert it to an empty result. The MCP SDK
   reports tool exceptions to the client; preserving the distinction between
   “not found” and an empty valid answer is part of the T1.6 seam.
8. The adapter imports and calls `RealToolLayer`; it must not copy parser,
   graph, slice, copybook, execution, or retrieval logic.

## Gates

- A registry gate asserts exact eleven-tool parity and no extra public tools.
- Delegation gates use `StubToolLayer` to prove representative structured
  outputs and `run_cobol` input construction without a compiler or provider.
- Configuration gates prove the CLI fails closed without a corpus and that
  environment/CLI copybook paths are deterministic.
- The existing T1.6 real/stub contract and consumer-semantics tests stay green.
- Full offline pytest, `ruff check .`, `ruff format --check .`, and
  `git diff --check` pass.
- `STATUS.md` records T7.1 done and the Track A inbox is empty in the same
  commit. No provider/API spend.

## Exclusions

- Streamable HTTP, OAuth, TLS, multi-tenant isolation, container images,
  Ollama/GGUF, and the on-prem deployment guide (T7.2).
- Changes to `tool_types.py`, `tools.py` signatures, `schemas.py`, or
  `docs/CONTRACT.md`.
- New raw-source endpoints or widened line/text caps.
