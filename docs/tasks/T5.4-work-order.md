## Objective

## Artifact reuse rule

M4 artifacts may be projected onto benchmark v1 only when every one of the 196
surviving v1 test IDs has exactly one matching M4 record and its source hash,
detector-visible clause, model settings, prompts, tools, and schema identity
match. The 8 manifest-listed exclusions are dropped explicitly and recorded in
the reuse decision; they must not be scored or treated as missing predictions.
Gold-only final-review changes may be rebound for scoring and must be listed.
Any detector-visible change or missing surviving ID forces the affected system
to rerun before the report is evaluable.

- overall and local/interprocedural T1 with answer rate;
- T2 localization and T3 macro-F1 for structured systems;
- agent T4 faithfulness by complete verification tier and calibration;

annotation record, or paired row is absent. A disappointing valid result is
still the result.
