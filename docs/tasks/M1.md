# M1 — Simplify migration

**State:** done (2026-10-07)

## What changed

Replaced about 2,000 lines of review, roster-signing, protocol-hashing, and
evidence-pinning code with four small modules:

- `migration/case.py` — `MigrationCase` (finding, `finding_source`, hosts,
  edit scope, intended behaviour, fixture checks, source assertions).
- `migration/patch.py` — parse and apply modification-only unified diffs.
- `migration/validate.py` — patch applies, edit scope, compile every host,
  source assertions, intended fixtures fail before the patch, every fixture
  passes after it.
- `migration/run.py` — `generate` (Luna via `eval/codex.py`), `validate`,
  `report`.

Data: one directory per case under `data/migration/`; the authoritative
fixtures were recovered from the archive (the versions pinned by the official
validation hashes). The old roster, review, capture, and receipt files are
gone.

## Result

Re-validating the four stored patches with the new engine in WSL
(GnuCOBOL 3.2.0): **4 passed, 0 failed**. All four findings are `oracle`
(benchmark gold), so they are an upper bound, not detector-led evidence.
Detector-led migration needs a `GO` decision first.
