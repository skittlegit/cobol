# T6.1 work order — migration and temporal evaluation freeze

**Owners:** Track B / Track C  
**State:** reactivated 2026-08-24; preparation in progress  
**Depends on:** frozen benchmark v1 and annotation protocol  
**Canonical artifacts:** `data/benchmark/t6-v2/`,
`data/migration/cases.jsonl`, `tests/test_t6_v2.py`

## Objective

Freeze two inputs without mutating benchmark v1: an independently reviewed
temporal add-on containing at least 20 intact version pairs, and a balanced
migration case roster with explicit intended and unaffected behavior.

## Temporal-pair gates

- At least 20 intact pairs; both sides share the same code input and differ in
  the applicable regulation version and correct judgment.
- Previously excluded ambiguous candidates are not silently restored.
- Explicitly non-human AI-primary labels are produced by fresh one-item
  `gpt-5.6-sol`/`max` contexts, receive a distinct fresh one-item
  `gpt-5.6-luna`/`max` verification pass, and require explicit adjudication.
- Pair IDs, source/clause hashes, versions, effective dates, gold-hidden model
  inputs, and split order are immutable before T8.3 smoke.
- No pair enters train/dev prompt development.

## Migration-case gates

- The roster is selected before configuration-3 test results are read.
- It covers available D1-D6 classes, local/interprocedural cases, executable
  batch programs where available, and statically checkable CICS programs.
- Each case freezes intended behavior changes, unaffected regression behavior,
  allowed source scope, and validation capability.
- Gold and oracle evidence are stored separately from detector-visible inputs.

## Completion

T6.1 completes when schemas, counts, review evidence, hashes, and leakage gates
are committed. No migration patch may be generated before this freeze.

## 2026-08-24 implementation checkpoint

The candidate construction, opaque sequential packet, frozen AI-primary
policy, isolated Sol/max primary and Luna/max verifier runner, resumable
immutable raw audits, and fail-closed promotion validator are implemented. The
amendment is explicit that AI-primary is not human review. Promotion remains
blocked until both controlled 22-side passes and any disputes are adjudicated.
