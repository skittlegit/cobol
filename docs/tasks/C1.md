# C1 — Consolidate the repository to one clean version

**State:** done (2026-10-07)

## Goal

Remove historical lineages, duplicate run paths, and process scaffolding so
there is one implementation and one current copy of every artifact.

## What changed

- Snapshot tag `archive/pre-consolidation` holds the full prior tree.
  Untracked raw provider logs were moved to `C:\Users\deepa\cobol-archive\`.
- Removed `FLAGS.md`, `BACKLOG.md`, `RELEASE.md`, `docs/CONTRACT.md`,
  `docs/legacy`, `docs/reviews`, all 52 old work orders, about 65 one-off
  scripts, `data/eval/{m4,m5,legacy}`, migration review and coordination
  evidence, `deploy/qualification`, and generated release and paper outputs.
- Replaced the stacked config-3/config-4/phase-5/collaboration/ablation
  runners and the OpenAI/Ollama providers with one path:
  `eval/{codex,bridge,detector,baselines,runner,report}.py`.

- Flattened benchmark files: `data/benchmark/{train,dev,test}.jsonl`,
  `data/benchmark/temporal/{rows.jsonl,pairs.json,programs/}`.
- Results: `data/eval/test/{detector,rag_reranker}.jsonl`,
  `data/eval/temporal/detector.jsonl`, `data/eval/test/report.{json,md}`.
- New `CLAUDE.md`, `STATUS.md`, `docs/architecture.md`, and task files;
  simplified `.gitignore`, `.gitattributes`, and CI.
