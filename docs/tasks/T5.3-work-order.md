# T5.3 work order — complete baseline suite

**Owner:** Track C  
**State:** ratified 2026-07-27; implementation in progress  
**Depends on:** T5.2 frozen benchmark for final artifacts; M4 record closed  
**Canonical artifacts:** `src/cobol_archaeologist/eval/phase5.py`,
`data/eval/m5/baselines/`

## Objective

Complete the benchmark-first comparison suite without changing the agent,
verifier, M4 prompts, or benchmark labels in response to results. Every
baseline receives only the information declared below and runs over the exact
frozen T5.2 test order.

## Frozen suite

The seven baselines are:

1. **Train-majority:** full-coverage binary verdict fixed from the frozen train
   prevalence.
2. **Prevalence-random:** deterministic SHA-256 draw per instance against the
   same train prevalence; seed identity is `m5-random-v1`.
3. **Static/keyword:** deterministic clause-value and content-token matching
   against materialized source, with no labels, mutation metadata, retrieval,
   model, or edit-history cues.
4. **Plain single-shot LLM:** clause plus bounded code context, no retrieval,
   tools, loop, oracle variables, or prior prediction.
5. **Dense-RAG single-shot:** explicit dense retrieval plus the same bounded
   code context and one model turn.
6. **RAG+reranker single-shot:** explicit hybrid retrieval and cross-encoder
   reranking plus the same bounded code context and one model turn. The M4
   artifact historically named `dense_rag` used `RegulationSearch`'s pinned
   `hybrid_rerank` default and is this baseline when its input identity matches.
7. **Attacker with bases:** the exact registered six-feature logistic probe
   fitted on `t2.2_surface_probe.jsonl`, applied to base/current source pairs.
   It may diff against published bases but receives no class, operator,
   mutation note, gold rationale, or label.

The agent is the headline system and oracle-slice remains a separately reported
deconfounder; neither is counted among the seven baselines.

## Predeclared surface-floor rule

Before any M5 headline result, the agent is required to beat the
attacker-with-bases baseline by at least **+0.10 binary T1 F1**, with the paired
bootstrap 95% interval on agent-minus-attacker excluding zero. This is an
evaluation-integrity floor, not a replacement for the CONTRACT headline bars.

## Gates

- All offline baselines are deterministic under reordered input and never read
  gold until constructing the paired evaluation record.
- Static/keyword and attacker inputs contain no provenance mutation, operator,
  labels, rationale, edit history, mtime, or comment-freshness features.
- The attacker uses all and only the six registered T2.2 features and records
  its fitted coefficients and source-probe hash.
- Provider baselines use the same frozen model family, reasoning effort,
  schema, verifier, bounded context, and test order. Smoke validity gates run
  before full execution.
- Every emitted LLM finding passes the unchanged T3.4 verifier; abstentions
  count as misses.
- Results report binary T1 overall and per locus stratum, answer rate,
  classification where structured output exists, and paired intervals.

## Exclusions

- No tuning against test results.
- No change to verifier thresholds, evidence minima, prompts, or labels after
  observing a baseline score.
- No provider run before the immutable T5.2 split exists.
