# Legacy work-order policy

This directory is reserved for superseded human-facing work orders that must
remain available outside Git history. The active work orders keep stable,
unversioned names in `docs/tasks/`.

Do not move hash-bound evaluation artifacts here. Schema versions, numbered
configurations, run lineages, attempts, and benchmark versions are part of
their audit identity. Their current selection belongs in the unversioned
project dashboard or manifest, while their bytes and declared paths remain
immutable.
