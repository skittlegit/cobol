# T4.1 schema-v3 paired rerun plan

**Owner:** Track C · **Status:** predeclared, blocked on review and paid-run
authorization · **Ratified inputs:** 2026-07-25

This plan replaces the invalid M4 attempt as a future execution plan; it does
not reinterpret or overwrite that attempt. The six artifacts under
`data/eval/m4/` remain diagnostic evidence. Schema-v3 outputs go under
`data/eval/m4-v3/`.

## Frozen configuration

Every smoke, pilot, and promoted full run uses:

- model `gpt-5.6-luna`;
- `reasoning.effort="low"`;
- temperature parameter omitted (Luna rejects it when reasoning is enabled),
  seed `None`, provider storage disabled;
- prompt `m4-live-openai-v4`, schema version `3`;
- Responses JSON mode (`text.format.type="json_object"`), with the complete
  response contract supplied in the input and enforced by the existing
  Pydantic contract gate;
- the same repository commit, input revision, split hash, tool version, and
  per-system budget recorded in each manifest.

The model or effort level must not change after inspecting results. A change
requires a new predeclared smoke and a complete paired rerun for agent,
dense-RAG, and oracle-slice.


complete 5/5 with zero infrastructure failures and `validity.status == "VALID"`.

missing, failed, stale, or mismatched smoke. There is no production smoke-skip
flag.

## Stage 4 — full paired rerun

```powershell
.\.venv\Scripts\python.exe -m cobol_archaeologist.eval.live --system all --model gpt-5.6-luna
```

The runner halts before the next paid row if contract rejections exceed 10%
after at least five provider responses. A completed artifact is still invalid
when agent mean successful observations are below 1.0 or its final verified
prediction rate is zero. Preserve every failed gate in the manifest.

M4 scoring/reporting begins only after all three schema-v3 artifacts are
complete, share the frozen run identity, have zero infrastructure failures,
and report `VALID`. The pilot cannot replace the full 204×3 paired run or its
