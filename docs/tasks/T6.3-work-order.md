## Objective

Validate intended regulatory behavior changes while rejecting unrelated
behavioral, structural, or source-scope regressions.

## Validation tiers

- Batch programs: pinned GnuCOBOL compile plus executable behavioral tests.
- CICS programs: parser, call-graph/dataflow/slice, source-locus, and applicable
  static/fixture checks; lack of GnuCOBOL executability is reported explicitly.
- Copybook changes: compile/static fan-out checks across every affected host.

## Gates

- intended behavior test passes;
- all frozen unaffected regression tests pass;
- changed files and lines remain inside the allowed case scope;
- no new parser errors, unresolved references, or verifier conflicts;
- patch applies cleanly to the frozen source hash; and
- every failure retains logs and is scored as failure or abstention, never
  silently dropped.

The primary migration metric remains behavioral-test pass rate. Intended
differences must align with the verified drift evidence; detector-led and
oracle-assisted results are never pooled.

## 2026-08-24 implementation checkpoint

Offline validation, deterministic report-time replay, pre-frozen reviewer-key
protocols, and a case-pinned validator/backend registry are implemented. The
combined migration suite is 30/30 green. GnuCOBOL is not available locally, so
real compilation evidence remains unavailable until execution occurs in a
pinned runtime that provides it; static and behavioral fixtures still fail
closed rather than converting unavailability into a pass.
